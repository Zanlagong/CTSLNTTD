# CTSLNTTD
有需求CTSLNTTD 汉藏小说翻译数据集的，请需发送用途说明至E-mail：zlg@stu.utibet.edu.cn审核获批后获取数据。


仓库简介
CTSLNTTD:  A dataset for translating sentence-level Chinese and Tibetan novel texts
CTSLNTTD：汉藏句级小说文本翻译数据集
This repository is the open-source homepage of the CTSLNTTD Chinese-Tibetan parallel corpus for novel machine translation research. The construction of this parallel dataset consumes abundant time, manpower and corpus collation costs, and the full dataset is not publicly available for direct download in this repository.
数据集获取说明
本数据集整理、标注、校对工作量巨大，仓库内不直接上传完整源数据文件。任何个人、科研单位、高校课题组若需要使用CTSLNTTD数据集开展学术研究、课题实验等相关工作，请通过邮箱发起使用申请：📩 联系邮箱：zlg@stu.utibet.edu.cn邮件内容请写明：使用人 / 团队名称、所属单位、数据集具体使用用途、研究方向，我审核通过后统一分发数据集资源。
数据集适用范围
本数据集仅限学术科研用途，禁止私自二次分发、商用售卖、爬虫倒卖、整合打包公开上传至其他平台，未经作者许可擅自流转数据集将追究相关使用责任。
配套说明
本仓库后续会持续更新数据集介绍文档、论文相关补充说明、数据集统计指标、实验基线配置文件等辅助资料；
对应学术论文已投稿 / 发表，引用本数据集请参照论文规范标注数据集名称：CTSLNTTD（汉藏句级小说文本翻译数据集）。
